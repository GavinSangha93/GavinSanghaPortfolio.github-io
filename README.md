## Featured Projects

- **[Medical Appointment No-Show Analysis](https://github.com/GavinSangha93/Medical-Appointments) — MySQL and Tableau:** Cleaned and analyzed 110,519 appointment records, evaluated drivers of missed visits, created patient-level risk tiers with CTEs and window functions, and built an interactive operational dashboard.
- **[Global Layoffs Data Cleaning](https://github.com/GavinSangha93/Global-Layoffs-Data-Cleaning) — MySQL:** Removed duplicates, standardized inconsistent fields and dates, addressed missing values, and prepared a global layoffs dataset for reliable analysis.
- **[Bike Sales Dashboard](https://github.com/GavinSangha93/Bike-Sales-Dashboard) — Excel:** Used PivotTables and an interactive dashboard to analyze demographic and lifestyle factors associated with motorcycle purchases.
- **[Airbnb Market Analysis](https://github.com/GavinSangha93/AirBnB-Market-Analysis) — Tableau:** Examined pricing, revenue, bedroom performance, and ZIP-code patterns in the Seattle short-term rental market.
- **[Data Professional Survey Analysis](https://github.com/GavinSangha93/Data-Professional-Survey-Analysis) — Power BI:** Analyzed salary, job satisfaction, programming preferences, and entry barriers across data-related careers.
