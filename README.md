# Gavin Sangha — Data, Business & Operations Analytics Portfolio

This repository contains my personal analytics portfolio website. It presents selected projects in SQL, Excel, Tableau, and Power BI, with an emphasis on data cleaning, dashboard development, business analysis, and translating data into practical decisions.

## Live Website

[View the live portfolio](https://gavinsangha93.github.io/GavinSanghaPortfolio.github-io/)

## Featured Projects

- **Medical Appointment No-Show Analysis — MySQL and Tableau:** Cleaned and analyzed 110,519 appointment records, evaluated drivers of missed visits, created patient-level risk tiers with CTEs and window functions, and built an interactive operational dashboard.
- **Global Layoffs Data Cleaning — MySQL:** Removed duplicates, standardized inconsistent fields and dates, addressed missing values, and prepared a global layoffs dataset for analysis.
- **Bike Sales Dashboard — Excel:** Used PivotTables and an interactive dashboard to analyze the demographic and lifestyle factors associated with motorcycle purchases.
- **Airbnb Market Analysis — Tableau:** Examined pricing, revenue, bedroom performance, and ZIP-code patterns in the Seattle short-term rental market.
- **Data Professional Survey Analysis — Power BI:** Analyzed salary, job satisfaction, programming preferences, and entry barriers across data-related careers.
